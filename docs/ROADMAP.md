# OpenDot 路线图

按可验收的功能持续推进。用户于 2026-11-09 调整优先级，要求今天优先达到真实对话能力，并持续每日更新。每次发布须通过检查并可用现有 Docker Compose 部署到 3300 端口。

规格来自《OpenDot 产品功能图文展示》：自托管个人 AI 助手和团队，界面为简体中文。没有配置模型时必须能以演示模式打开。

## 第 1 天 · 骨架与底座

项目骨架、中文基础布局、GitHub Actions、首次部署。

- 桌面左侧栏，手机底部「小点 / 团队 / 工作 / 设置」
- 主界面能看到「小点」和欢迎语，其余页面是空态
- 健康检查、README、这条路线图
- 推到 `main` 后可以部署；服务器上已有的容器不动

## 当前优先里程碑 · 和小点真实对话

合并原第 2 天与第 12 天的核心能力，完成真实流式对话与无密钥演示模式。

- 欢迎语「今天需要我帮你处理什么？」
- 消息列表、输入框、Enter 发送
- OpenAI 兼容服务真实多轮回复、流式显示、用量记录
- 无密钥时规则回复并明确标记演示模式
- 登录保护、模型配置加密保存、失败重试与请求去重
- 刷新后对话还在（SQLite）

## 第 3 天 · 自定义 Dot 与团队

- 新建 Dot：形状、颜色、名字、可选角色说明
- 「我的 Dot」列表：角色、默认模型、最近对话、「开始对话」
- 详情里先放「对话 / 当前工作 / 能力 / 记忆 / 设置」五个标签，后三个可以先是说明，不要做成空壳按钮

## 第 4 天 · 会话放进导航

- 每个 Dot 一条直接会话
- 桌面侧栏 DOTS、RECENT
- 手机「小点」页是会话列表，点进去才是对话
- 搜索框能按名字过滤

## 第 5 天 · 群聊与 @

- 新建群聊，勾选要加入的 Dot
- 输入 `@` 选择成员
- 新群默认「仅在 @机器人 时回复」
- 群里可以用 `/require_mention` 或群设置切换
- 被点名的 Dot 在演示模式下各自回一句

## 第 6 天 · 新建委托

- 「我的工作」：全部 / 进行中 / 需要你处理 / 已完成 / 计划与例行
- 新建目标：目标、完成条件（每行一条）、工作区、下一步、最多执行次数（1–10000，默认 10）
- 创建后出现在列表里。这一天可以先不真正执行

## 第 7 天 · 推进委托

- 详情页：完成条件、下一步、执行预算
- 开始执行、暂停、继续、取消
- 继续时沿用同一次执行
- 没有证据不能标记完成；声明了设备时还要设备证据
- 单次运行最多 12 步、默认最长 30 分钟，先记在数据和界面上

## 第 8 天 · 审批卡片

- 演示回复里，写入、发送、删除、成稿先变成「创建私有文本成果」
- 批准只对卡片上的精确内容有效，改一个字就拒绝
- 私有成果最大 64 KiB，路径不由 Dot 选择，不能覆盖已有文件
- 结果加密写入账本。无法确认时标记「不确定」，不盲目重放

## 第 9 天 · 需要你处理

- 把待批准、等待设备、等待输入收进收件箱
- 每条都能「查看任务与审批」
- 侧栏显示未处理数量
- 设备类卡片写明：只对这一次读取有效，不能扫描目录或写入

## 第 10 天 · 工作区记忆

- 四类：事实、决策、经验、待跟进
- 新建、搜索、版本、忘记
- 忘记一条记忆不删除聊天记录
- 个人记忆需要逐条授权才能跨工作区使用。Mem0 只做开关，默认关闭

## 第 11 天 · 设置与外观

- 个人资料：显示名、表情头像。不改 Dot 的名字
- 常规：排队 / 引导，Ctrl+Shift+Enter 临时切换
- 浅色、深色、跟随系统；配色；字体
- 主题在页面绘制前生效，避免首帧闪白
- 明暗两套都要能看侧栏、对话、群聊和工作页

## 模型提供商 · 已提前纳入当前里程碑

- 设置页填写 OpenAI 兼容 Base URL、API Key、模型名
- 环境变量优先于数据库里保存的值
- 有密钥就走 `{BASE_URL}/chat/completions`
- 没有密钥保持第 2 天的演示模式
- 密钥不明文回传给浏览器

## 第 13 天 · 渠道与设备

简化，但要能操作。

- 七个渠道：飞书、Telegram、QQ、微信、钉钉、Discord、WhatsApp
- 新群默认响应方式；错误的 `/pair` 配对码拒绝
- Telegram 可以尝试校验 Token，不要求真的 webhook
- 设备节点默认关闭。开启后能生成配对码，并用「模拟本地节点提交」完成配对
- 设备离线时任务等待原设备，不改派

## 第 14 天 · 定时任务、用量与 PWA

- 定时任务：一句话创建，以及 cron / 固定间隔 / 单次
- 到点若有副作用，改成审批，不直接执行
- 用量页可导出 CSV
- 能力库只登记 MCP 和技能，不拉起宿主机进程；MCP 首次启用要同意
- PWA：manifest、可安装、离线时显示「无法连接服务端」和重试
- 对照规格把文案和空态再过一遍，不扩大范围

## 每天都要保持的底线

- 简体中文界面
- `npm run lint`、`npm run typecheck`、`npm test`、`npm run build` 通过
- 数据放在卷里，重新部署不丢
- 不停止、不改已有的 Caddy、Uptime Kuma、Portainer、sub2api
- 不把 SSH 私钥、API Key 或 `.env` 提交进仓库
